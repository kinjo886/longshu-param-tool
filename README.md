# 参数处理工具（浏览器扩展）

> 开源脱敏版。原项目为某政务数据治理平台的「作业入参处理工具」，本仓库已移除内部域名与项目代号。

Chrome / Edge 扩展（Manifest V3）：批量解析云表格逗号参数，生成标准二维数组 JSON。

## 安装

1. 打开浏览器 `chrome://extensions`（或 `edge://extensions`）
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本目录下的 `longshu_param_tool/` 文件夹
4. 点击扩展图标或侧边栏打开工具

详见 `longshu_param_tool/manifest.json` 与 `panel.html`。
